Component Tree — Phase 1 (Homepage)

Root-level app/ directory, no src/. Every module from the vanilla site maps to a specific React file.

Project root file tree
app/
  layout.tsx — dir="rtl" lang="he", ThemeProvider, <Cursor />
  page.tsx — Homepage: assembles Hero + Process sections
  providers.tsx — ThemeContext: dark/light + accent (indigo/jade/copper)
  globals.css — Tailwind base + 6 theme token sets as CSS vars

components/
  layout/
    Navbar.tsx — Fixed, RTL: logo right, nav left, CTA button
    Footer.tsx — Auto year, RTL-aligned

  ui/
    Cursor.tsx — Dot + ring, hidden on touch via media query
    ThemeSwitcher.tsx — Side panel: 2 mode buttons + 3 accent swatches
    Modal.tsx — 3-step WhatsApp lead capture, circle reveal
    MagneticButton.tsx — Wrapper: pulls toward cursor within 80px radius

  three/
    BlobScene.tsx — R3F <Canvas> + morphing blob mesh + 2000 particles
    BlobMesh.tsx — ShaderMaterial with existing vert/frag shaders
    Particles.tsx — Points geometry, orbiting + scatter on scroll velocity

  sections/
    Hero.tsx — Full-viewport, BlobScene behind text, GSAP reveal on load
    Process.tsx — 3 glass cards, ScrollTrigger stagger, 3D tilt on hover

hooks/
  useTheme.ts — Reads/writes ThemeContext + syncs data-theme on <html>
  useCursor.ts — Mouse tracking, lag lerp, magnetic pull, spotlight effect

lib/
  theme.ts — 6 token maps (dark/light × indigo/jade/copper)
  whatsapp.ts — Message builder → wa.me/972547492977
