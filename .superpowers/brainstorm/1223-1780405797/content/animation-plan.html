Animation Plan — Homepage

Three layers of motion: load reveal, scroll triggers, and pointer interaction. All GSAP via useGSAP with automatic cleanup on unmount.

Layer 1 — Load reveal (fires once on mount)

0s R3F Canvas fades in (opacity 0→1, 1.2s ease) 0.3s Navbar slides down from −60px + fade (0.6s) 0.6s Hero chip tags stagger in (translateY 20px→0, 0.4s each, 0.1s apart) 0.9s H1 words slide up from clip (each word wrapped in overflow:hidden span, 0.5s stagger) 1.3s Subtitle + CTA buttons fade up (0.5s, slight delay between them)

Layer 2 — ScrollTrigger (fires as user scrolls)

Process section 3 glass cards stagger in: scale 0.92→1, opacity 0→1, translateY 40px→0, 0.15s apart Process section Section heading text slides in from right (RTL: from −40px) as cards enter BlobScene (R3F) Scroll velocity passed via ref → particles scatter on fast scroll, calm on idle Navbar Adds backdrop-filter blur + reduced opacity after scrolling 80px (CSS class toggle)

Layer 3 — Pointer interaction (continuous, per frame)

Custom cursor Dot follows mouse exactly. Ring lags with lerp 0.14. Both hidden on touch via CSS. Magnetic buttons MagneticButton wrapper: within 80px, element pulls toward cursor (GSAP quickTo). On leave: elastic snap back. Glass card tilt Process cards: mousemove → rotateX/Y ±8°, perspective 800px. Spotlight radial gradient follows cursor inside card. Reset on mouseleave. R3F blob Mouse position passed as uniform → blob subtly rotates toward cursor (existing shader logic).
