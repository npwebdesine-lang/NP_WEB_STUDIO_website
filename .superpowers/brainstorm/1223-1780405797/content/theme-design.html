Theme System Design — 6 Combinations

One data-theme attribute on <html> drives everything. Six values = 2 modes × 3 accents. ThemeSwitcher writes it; CSS variables respond instantly.

The 6 data-theme values

dark-indigo
dark-jade
dark-copper
light-indigo
light-jade
light-copper

How it works in code

/* globals.css — one block per theme */
[data-theme="dark-indigo"] { --bg: #0e1433; --text: #eef1fa; --accent: #8a95c9; ... }
 [data-theme="light-indigo"] { --bg: #f0f2fa; --text: #1a2050; --accent: #5a6abf; ... }
 /* ... 4 more blocks */

/* ThemeSwitcher writes: */
document.documentElement.setAttribute('data-theme', 'dark-indigo')

/* ThemeSwitcher UI: */
☀️ / 🌙 toggle + ● ● ● accent swatches (indigo / jade / copper)

Default

dark-indigo — same as today. Persisted in localStorage['np-theme']. On first visit, reads system preference (prefers-color-scheme) to pick dark or light, always defaults accent to indigo.
