Theme System — How many modes?

Your brief says "dark/light aesthetic." The current site has 3 dark themes (Night Indigo, Jade Dynasty, Burnished Copper). Which theme system should the Next.js app use?

A

Keep the 3 dark themes

Night Indigo / Jade Dynasty / Burnished Copper — exactly as today. Switcher panel stays. No light mode added. Best for brand consistency.

B

Dark + Light toggle only

Simple 2-mode system: one polished dark, one polished light. Familiar to users, easier to maintain. Drop the 3-color theme variation.

C

Dark/Light toggle + 3 accent colors

Best of both: dark & light modes each support the 3 palette choices (indigo / jade / copper). Most flexible — but more CSS to maintain.
